# IntercityTaxi 🚕🌍

IntercityTaxi is a backend-based taxi management system designed for interregional (viloyatlar aro) transportation.  
The project helps manage taxi routes, passengers, and trip information between different regions in Uzbekistan.

---

## 📌 Features

- 🗺 Intercity (viloyatlar aro) taxi route management
- 👤 Passenger information handling
- 🚕 Taxi and driver management
- 📍 Trip creation and tracking
- 🗄 Database-based data storage
- 🔐 Clean and structured backend logic

---

## 🛠 Technologies Used

- Java
- Spring Boot
- PostgreSQL
- Hibernate (JPA)
- REST API
- Maven
- Telegram bot (Java)

---

## 🚀 How the System Works

1. Taxi routes are defined between regions
2. Passenger requests are registered
3. The system assigns trips based on available routes
4. All trip data is stored securely in the database
